# Invoice Handler

Project developed for the Introduction to Data Structures and Algorithms (IAED) course at Instituto Superior Técnico.

## Overview
A command-line invoice management system written in C. The application handles the creation, storage, and manipulation of invoice records efficiently.

## Key Features
- **Data Structures:** Utilizes custom C data structures to manage memory and organize invoice data.
- **Modular Design:** Separates interfaces and implementations using `.h` header files.
- **Build Automation:** Includes a Makefile for automated compilation and clean-up.
- **Parsing:** Efficiently parses input commands and formats output data.

## Technologies
- C
- Makefile
- Data Structures

## How to compile and run
Run `make` to compile. Execute the generated binary to start the system.
